# Welcome to your workspace

This is a small, real project for trying Cursor Workbench.

## Try the editor
Open `src/hello.js` and `package.json` from Explorer. Edit a greeting and save with Ctrl+S.

## Give an agent a task
Ask an agent to read the project, add a function, and run `npm test`. File edits appear here immediately. Terminal commands wait for your approval in the Agents Window.

The project is shared by the Editor Window and all agents. The agent checks for conflicting edits before it writes a file. Review changes before accepting them.

## Run

```sh
npm test
node src/hello.js
```
